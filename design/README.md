# Design

Source for the app design: the "Map" boards (top bar, group view, Trash; shared styles in `mp.css`). The home screen follows the spectrum design on the canvas page "Home · Spectrum".

Opening a group and reading mail follow `Op-Combo.dc.html` ("A + 6" on that page): the group list shrinks to the left with its rows kept on one line, the group's emails slide in beside it, and each email opens in place.

These are Claude Design canvas files. They need the canvas runtime (`support.js`), so opening one directly in a browser shows unrendered templates. The app's real styles are in `../assets/style.css`.
